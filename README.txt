This game is about what kind of things cause distraction and what gives more focus. This game helps you to make 
better habits by making you choose whats better to your brain. 

This project is useful because this it helps you to make better habits to brighten your life.

To run this program, ensure you have Python 3 installed on you computer, and also download pygame.,
After that, just open terminal and run main.py to get started.
